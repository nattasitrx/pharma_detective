# สี่ชั้นของลุงหลี่ — ร่างบทวันที่ 1 "ลงไม่ได้"

ร่างแรกสำหรับอ่าน ยังไม่ได้ใส่ในเกม · ราว 8 นาที
[วงเล็บเหลี่ยม] = สิ่งที่ผู้เล่นทำหรือสิ่งที่เกิดบนจอ · เครื่องหมาย / = ขึ้นบรรทัดใหม่

สิ่งที่ผมแต่งเพิ่มจากเคส D (ขอให้ตรวจ): อาเหมยพาเจ้าดำมาเมื่อแปดปีก่อน, ลุงหุงข้าวใหม่ให้หมาแต่ตัวเองกินข้าวต้มค้าง, เพลงสี่โมงเย็นเป็นเพลงที่ลุงเคยเต้นกับเจ้าดำ, ปฏิทินจดว่าใครพาเจ้าดำลงไป

---

## 1. เช้า 06:10

[จอมืด เสียงพัดลม แล้วมีเสียงเล็บเดินบนพื้นไม้]

มีอะไรหนักๆ วางลงบนหน้าแข้งผม

[ภาพ: เจ้าดำคาบสายจูงสีแดง มองขึ้นมา]

เจ้าดำ / มันคาบสายจูงมาเองทุกเช้า หกโมงสิบนาที ไม่เคยผิด

ผมไม่เคยสอน / ผมแค่เคยพามันลงไปตอนหกโมงสิบนาที อยู่หลายปี

[กดค้างเพื่อลุก · ระบบฮึบเดิม ลุกไม่ขึ้นในครั้งแรก]

หนึ่ง สอง สาม / …ยัง

[กดค้างอีกครั้ง]

หนึ่ง สอง สาม สี่ ห้า / ขึ้น

เจ้าดำถอยให้หนึ่งก้าว / มันรู้ว่าผมต้องใช้ที่

## 2. โทรศัพท์ 06:40

[เสียงกริ่ง · แตะเพื่อรับ]

"เหล่าหลี่ ตื่นหรือยัง"

อาเหมย ภรรยาผม อายุสี่สิบเอ็ด / เธอเข้าเวรที่บ้านพักทหารผ่านศึกกังซาน กลับบ้านสัปดาห์ละสองสามวัน

"เจ้าดำล่ะ ลงไปหรือยัง"

[เลือก: "ลงแล้ว" / "กำลังจะลง"]

- ถ้าเลือก "ลงแล้ว": ผมโกหกเธอได้คล่องกว่าที่ควร
- ถ้าเลือก "กำลังจะลง": จริงครึ่งเดียว ผมกำลังจะลองลง

เธอเป็นคนพามันมา แปดปีก่อน / หมาดำตัวผอม ผูกเชือกฟางมากับจักรยาน

"ฉันเข้าเวรดึกบ่อย" เธอว่า "เธอจะได้ไม่ต้องอยู่คนเดียว"

ผมบอกว่าผมไม่ได้อยากได้หมา / คืนนั้นมันนอนทับเท้าผม

## 3. ยาเช้า 07:00

[ภาพ: กล่องยาใส ถุงยาสามใบจากสามที่]

หมอสามคน ถุงยาสามใบ / ผมกินตามที่ถุงบอกทุกถุง

[แตะเม็ดยาทีละกลุ่ม]

- ยาเบาหวาน: เมื่อคืนผมลืมมื้อเย็น / เช้านี้เลยกินสองมื้อรวมกัน ของหลวง ทิ้งไม่ได้
- ยาแก้แพ้: ถุงนี้หนึ่งเม็ด ถุงโน้นอีกหนึ่งเม็ด / ชื่อไม่เหมือนกัน ผมเลยคิดว่าคนละอย่าง
- ขวดสีน้ำตาล: อันนี้ไม่มีหมอคนไหนสั่ง / ผมซื้อเอง จากรถขายยาหน้าตลาด

ฉลากเขียนว่า บำรุงเข่า / คนขายบอกว่ากินสามเดือน จะลงบันไดได้เหมือนหนุ่ม

ผมกินมาห้าเดือนแล้ว

[ภาพ: หม้อบนเตา]

ข้าวต้มในหม้อ ต้มไว้ตั้งแต่วันเสาร์ / ผมตักใส่ชามตัวเอง

แล้วหุงข้าวใหม่หนึ่งกำมือ ให้เจ้าดำ

## 4. บันไดครั้งที่หนึ่ง 07:30

[ภาพ: บันไดมองลงไปจากชั้นสี่ เจ้าดำยืนรออยู่ขั้นล่าง]

สี่ชั้น ไม่มีลิฟต์ / ชั้นละสิบหกขั้น ผมนับไว้ตั้งแต่ยังไม่ต้องนับ

[แตะ ซ้าย-ขวา สลับกัน · แถบลมหายใจลดลงเร็ว]

ชั้นสี่ลงชั้นสาม / มือผมจับราวแน่นกว่าที่ตั้งใจ

[ภาพเริ่มเบลอขอบ เสียงหอบ]

ชานพักชั้นสาม / หน้าอกผมแน่น หัวผมเบา มือผมเย็น

[เลือก: "ลงต่อ" / "พัก"]

- "ลงต่อ": อีกสามขั้น แล้วบันไดก็เอียง
- "พัก": ผมนั่งลงบนขั้นบันได เจ้าดำเดินกลับขึ้นมานั่งข้างๆ

[จอมืดครู่หนึ่ง]

มีมือมาจับแขนผม

"คุณปู่ ผมพาเจ้าดำไปให้ไหมครับ"

เด็กหนุ่มห้องสี่ศูนย์หก / เขาถามแบบนี้ทุกเช้ามาสองเดือนแล้ว

[เลือก: "ยื่นสายจูงให้" (ตัวเลือกเดียว)]

เจ้าดำหันมามองผมหนึ่งครั้ง / แล้วก็เดินลงไปกับเขา

## 5. หน้าต่าง 07:50

[ภาพ: มองลงจากหน้าต่างชั้นสี่ เห็นเด็กหนุ่มกับเจ้าดำบนถนน]

จากข้างบน มันดูเล็กนิดเดียว

มันหยุดดมเสาไฟต้นเดิม / เด็กคนนั้นดึงสายเบาๆ เขารีบไปเรียน

ผมเคยยืนรอมันดมจนพอใจ

[ภาพ: ปฏิทินข้างเตียง · แตะเพื่อเขียน]

ผมจดไว้ทุกวัน ว่าใครพาเจ้าดำลงไป

[ผู้เล่นแตะช่องวันนี้ · ตัวหนังสือปรากฏ: "406"]

[กล้องถอยออก เห็นทั้งเดือน: "406" เรียงกันทุกช่อง · ปฏิทินพลิกย้อนไปสองหน้า จึงเจอคำว่า "ผม" ครั้งสุดท้าย]

## 6. สี่โมงเย็น 16:00

[ภาพ: วิทยุบนชั้น · เสียงซ่า แล้วเพลงดังขึ้นเบาๆ]

สี่โมงเย็น สถานีนี้เปิดเพลงเก่า

[ภาพ: เจ้าดำลุกขึ้น เดินมายืนตรงหน้า ยกขาหน้าขึ้นแตะเข่าผม]

มันจำได้

เมื่อก่อน พอเพลงนี้ขึ้น ผมจะลุก / มันจะยืนสองขา ผมจะจับขาหน้ามันไว้ แล้วเราก็หมุนกันอยู่กลางห้อง

อาเหมยหัวเราะจนต้องนั่ง

[กดค้างเพื่อลุก · ลุกไม่ขึ้น ไม่ว่ากดกี่ครั้ง]

วันนี้ไม่ไหว

[ภาพ: เจ้าดำเอาจมูกแตะหลังมือ]

มันเอาขาลง / แล้วเอาจมูกมาแตะหลังมือผมแทน

เรานั่งฟังจนจบเพลง

## 7. ตีสอง 02:10

[จอมืด เสียงน้ำหยด]

ห้องน้ำอยู่สุดทางเดิน ยี่สิบสามก้าว

[แตะ ซ้าย-ขวา ในความมืด · ก้าวที่สิบเก้า จอสั่น เสียงกระแทก]

[ภาพ: พื้นกระเบื้อง มองจากระดับพื้น]

พื้นเย็น

ผมลองขยับขา / สะโพกขวาตอบกลับมาทันที

[เสียงเล็บบนพื้น · ภาพ: เจ้าดำเดินมา นอนลงแนบข้างตัว]

มันไม่เห่า / มันแค่นอนลง ให้หลังมันติดกับซี่โครงผม

ตัวมันอุ่น

[เลือก: "เรียกคนช่วย" / "ไม่เรียก"]

- "เรียกคนช่วย": ผมอ้าปาก แล้วก็นึกออกว่าหลังจากนั้นจะเกิดอะไร
- "ไม่เรียก": (ไปต่อเลย)

คนแก่ที่ล้ม เขาไม่ให้อยู่บ้านคนเดียว / ลุงหวังห้องสามศูนย์สองล้มครั้งเดียว ลูกชายมารับไปอยู่บ้านพักคนชรา

ที่นั่นไม่รับหมา

[ภาพ: แสงเช้าเข้ามาทางช่องลม]

ตอนฟ้าสาง ผมลุกได้ / ใช้เวลานานกว่าที่จะเล่าให้ใครฟัง

เจ้าดำเดินนำกลับไปที่เตียง / หันมาดูทุกสามก้าว

## 8. ปิดวัน

[ภาพ: ปฏิทิน]

อีกสามวัน จะมีคนจากโรงพยาบาลมาเยี่ยมบ้าน

ผมซ่อนถุงยาไว้ในลิ้นชักแล้ว / ใส่กางเกงขายาว ปิดรอยช้ำ
