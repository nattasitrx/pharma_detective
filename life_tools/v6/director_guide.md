# เจ็ดวันของลุงหลี่ — คู่มือกำกับอารมณ์ (สำหรับผู้พัฒนา)

อ้างอิงสคริปต์: **เจ็ดวันของลุงหลี่_บทเกมฉบับกระทบใจ_v6_1.md**

## หลักการ

เกมไม่ได้บังคับให้ผู้เล่นร้องไห้ด้วยเหตุร้ายหรือการตาย แต่สร้างความผูกพันกับกิจวัตรเล็ก ๆ ของลุงหลี่ แล้วให้ผู้เล่นพบว่าการกระทำที่ดูเล็กน้อยของนักศึกษาเภสัชมีความหมายแค่ไหนในชีวิตคนที่กำลังรอใครสักคน

ผู้เล่นเคยเป็นนักศึกษาในเคส D มาแล้ว จากนั้นมาอยู่ในร่างผู้ป่วยเจ็ดวัน: การขออนุญาต การฟังให้จบ การไม่ดุ และการนัดติดตามจึงต้องรู้สึกเหมือนสิ่งที่ผู้เล่นเคยทำโดยไม่รู้ว่ามีน้ำหนัก

## จังหวะที่ห้ามรีบ

| วัน | การกระทำของผู้เล่น | สิ่งที่ควรเกิดทางอารมณ์ | การกำกับ |
|---|---|---|---|
| อังคาร | รอโทรศัพท์ / วางหู / แตะหัวเจ้าดำ / วางชาม | รู้สึกว่าการไม่มีใครโทรไม่ใช่เรื่องเล็ก | ให้เสียงนาฬิกาเด่นเฉพาะตอนรอ ไม่ใช้ดนตรีเรียกน้ำตา |
| พุธ | รับสาย / อยู่ห้องรอคิว / เห็นเจ้าดำมองหน้าต่าง | เริ่มผูกพันกับผู้หญิงที่โทรมาและหมาที่ไม่เคยเร่ง | ให้เสียงโทรศัพท์สองกริ่งเป็นสัญลักษณ์ซ้ำ |
| พฤหัส | คลำผนังหาห้องน้ำ / ลุกจากกระเบื้อง | เข้าใจว่าทำไมคนไข้จึงไม่เล่าความจริง | ห้ามทำเป็นฉากสยองขวัญหรือใช้อุบัติเหตุเพื่อกระตุ้นแบบฉาบฉวย |
| ศุกร์ | ฟังนักศึกษาถามผิดแล้วแก้คำถาม / ยอมให้เปิดลิ้นชัก | เห็นความต่างระหว่างการตรวจยา กับการมองเห็นคนหนึ่งคน | ให้ผู้เล่นตัดสินใจเรื่องการไว้ใจ; อย่าทำให้นักศึกษาเป็นฮีโร่ |
| เสาร์ | ลงถึงชั้นสอง / รอให้เจ้าดำดมประตู | รู้สึกว่าการรอให้ใครสักคนเป็นความรักอีกแบบหนึ่ง | ไม่ต้องมีข้อความว่า ‘ซึ้ง’ หรือ ‘เศร้า’ |
| อาทิตย์ | จัดยาเอง / ได้ยินอาเหมยเล่าถึงพ่อ / ยื่นหรือไม่ยื่นสมุด | ย้อนนึกถึงคนที่เคยถามว่า ‘กินยาหรือยัง’ | ช่วง ‘หนูก็นับกริ่งเหมือนกัน’ ให้เว้นจังหวะก่อนประโยคถัดไป |
| จันทร์ | จูงเจ้าดำ / ยกมือให้อาเหมย / แตะเพื่อจับมือในฉากเต้น | คลายปมเดิมโดยไม่ย้อนเวลาไปแก้อดีตได้ | ให้ภาพแม่วัยก่อนค่อย ๆ กลับเป็นมืออาเหมยในปัจจุบัน ไม่มีปาฏิหาริย์ |

## สามวัตถุที่ต้องมีภาพและเสียงจำได้

1. **โทรศัพท์**: กริ่งที่หนึ่ง-สองมีจังหวะเดิมทุกครั้ง แต่เปลี่ยนความหมายจากการแกล้งไม่รอ เป็นการยอมรับว่ารอกันทั้งคู่ ตอนภาพปิด ผู้เล่นแตะหูโทรศัพท์เอง
2. **สายจูงเจ้าดำ**: ห้ามเร่งแอนิเมชันการที่หมาหยุดรอ ผู้เล่นควรได้เป็นฝ่ายรอมันคืนหนึ่งด้วย
3. **ชามใบที่สอง**: ตั้ง-เก็บ-ตั้งซ้ำอย่างธรรมดา ห้ามซูมชามพร้อมเพลงเศร้าในวันแรก พอถึงท้ายเรื่องผู้เล่นจะจำมันได้เอง

## การกำกับเสียงและภาพ

- ใช้เสียงห้อง แรงหายใจเบา ๆ วิทยุ เสียงฝาฝืดของกล่องยา เสียงก้าวบนบันได มากกว่าเพลงประกอบ
- ดนตรีมีได้ แต่ไม่ควรดังขึ้นอัตโนมัติทุกครั้งที่มีข้อความเศร้า ใช้ความเงียบเป็นส่วนหนึ่งของเรื่อง
- ข้อความแต่ละจอให้ผู้เล่นกดต่อเมื่อพร้อม ฉากรอใช้จังหวะเล็ก ๆ แต่ไม่ล็อกผู้เล่นอยู่ในหน้าจอเป็นเวลานาน
- มือของตัวละครสำคัญกว่าภาพใบหน้าที่แสดงอารมณ์เกินจริง: มือที่หย่อนให้หมาดม มือที่ค้างบนลิ้นชัก มือที่แตะกันตอนเพลงจบ
- ตัวเลือกเกี่ยวกับยาไม่ควรถูกทำให้ดูเป็น ‘คำตอบที่ถูก’ หากเป็นพฤติกรรมเสี่ยง ผลลัพธ์ต้องสอดคล้องกับเงื่อนไขและการดูแลต่อเนื่อง
- กำหนดโหมดข้ามแอนิเมชัน/ลดการเคลื่อนไหวได้ เพื่อไม่ใช้ความช้าบังคับอารมณ์คนเล่น

## ทดสอบต้นแบบก่อนปล่อยจริง

ทดสอบกับนักศึกษาเภสัชอย่างน้อยสองกลุ่มเล็ก ๆ: คนที่เคยเล่นเคส D และคนที่ยังไม่เคยเล่น ให้เล่นโดยไม่มีคนอธิบายเจตนาล่วงหน้า จากนั้นถามว่า:

- ‘ช่วงไหนที่คุณยังจำภาพหรือเสียงได้หลังเล่นจบ?’
- ‘คุณรู้สึกอย่างไรตอนลุงหลี่ถูกถามเรื่องยาข้ามหัว?’
- ‘ถ้าได้กลับไปเยี่ยมคนไข้จริง ๆ คุณจะทำอะไรต่างจากเดิม?’

บันทึกช่วงที่ผู้เล่นหยุดอ่าน กลับไปแตะวัตถุเดิม หรือเลือกจะเล่าความลับ ไม่ต้องใช้จำนวนคนร้องไห้เป็นเกณฑ์คุณภาพเพียงอย่างเดียว

## ตรวจสอบก่อนลงเกม

- สคริปต์เป็นบทเชิงสร้างสรรค์และมี metadata ของเงื่อนไขบทสนทนา **ยังไม่ได้ผูกเข้ากับเอนจินเกมหรือทดสอบเล่นทุกทางเลือกจริง**
- รักษาลำดับ 7 วันและข้อเท็จจริงเคส D โดยให้ผู้สอนด้านเภสัชกรรมตรวจการใช้ยา การประเมินหกล้ม และคำแนะนำความปลอดภัยก่อนเผยแพร่
