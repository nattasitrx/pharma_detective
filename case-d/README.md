# Pharma Detective · เคส D: ความลับของลุงหลี่ (李伯伯的秘密)

ตัวเกมอยู่ในไฟล์ `case-d/index.html` ไฟล์เดียว ใช้ระบบเดียวกับเคส A และ C ทุกอย่าง มี 3 ภาษา (จีน / อังกฤษ / ไทย)
และเก็บผลการเล่น เหรียญ และเกมที่เล่นค้างแยกจากเคส A/C

## ข้อมูลที่นำมาจากเคสจริง
- ชาย เกิด 1933/05/01 สูง 167 ซม. หนัก 62 กก. (BMI 22.2) ทหารผ่านศึกจากชิงเต่า อยู่คนเดียวในห้องเล็ก 5 ผิง ชั้น 4 ที่ Jingzhong New Village (ครัว/ห้องน้ำใช้ร่วมกัน) เลี้ยงสุนัข
- ภรรยาเกิด 1981 มาจากจีนแผ่นดินใหญ่ ทำงานเป็นกะที่บ้านพักทหารผ่านศึกกังซาน นานๆ กลับบ้านที ช่วยเรื่องเงินบ้าง อายุห่างกันมากจึงมีปากเสียงกัน
- ไปพบแพทย์ 93 ครั้งในปี 2021 → สปสช. ส่งต่อให้เภสัชกรเฉินเยี่ยมบ้าน
- โรค: COPD, HTN, BPH, DM2, ผื่นภูมิแพ้ผิวหนัง, เหงือกอักเสบซ้ำ, ภูมิแพ้จมูก, ข้อเข่าเสื่อม, GERD, ต้อกระจก
- อาการ: เวียนหัวบ่อย อ่อนเพลีย เสมหะขาวข้นมาก ผื่นแดงคัน (เหงื่อออกแล้วแย่ลง) เหงือกบวมปวด น้ำมูกตอนเช้า ปัสสาวะลำบาก ปวดเข่า ปวดท้อง ขึ้นบันไดแล้วหอบ
- ห้องร้อน อากาศไม่ถ่ายเท อาหารบูด มีมด ไม่ยอมเปิดแอร์เพราะกลัวค่าไฟ ทำความสะอาดฟันปลอมโดยแช่ในแก้วโลหะใส่น้ำ
- ลืมกินยา แล้วกินชดเชยผิดเวลา ใช้ยาพ่นผิดวิธี (กดกับหายใจไม่สัมพันธ์ พ่นแล้วถุยออก) และสับสนยาฉุกเฉินกับยาควบคุมอาการ
- ซองยา รพ.ทั่วไป อายุรกรรมทรวงอก 6 ซอง + ต่อมไร้ท่อ 5 ซอง (111/04/28), รพ.เทศบาล ผิวหนัง 3 รายการ (111/03/12), ใบเสร็จคลินิกเวชศาสตร์ครอบครัว (111/03/20)
- ผลแล็บ 3 ครั้ง: HbA1c 7.2→7.9→8.2, TG 193, TC 222, LDL 138, Cr 1.0 → 0.5 → 0.8

## สิ่งที่แก้ในรูปตามที่ทีมตกลง
- อายุบนซองยาทุกซอง 85 → **88** (ให้ตรงกับวันเกิด 1933/05/01 ณ วันที่จ่ายยา)
- ใบผลแล็บ: สลับค่าอ้างอิง **TG 35–160** และ **TC 140–200** ให้ถูกต้อง
- ซอง Dermalin ของ รพ.เทศบาล: เลขรายการที่ซ้ำ "3-1" → **"3-3"**
- **ยังไม่แก้:** ซองที่จำนวนครั้งต่อวันไม่ตรงกับเวลาที่กิน (Galvus MET, Minidiab, Sketa, Actibest) ทีมจะถามอาจารย์ก่อน ในเกมแสดงตามที่พิมพ์บนซอง และไม่ได้นำมาเป็นปัญหาให้หา (ในคู่มือ debrief มีหมายเหตุไว้)

## ต้องยืนยันกับอาจารย์
- **Royamet 200 mg** ในใบเสร็จคลินิก: เกมถือว่าเป็น **cimetidine** (H2 blocker) → ซ้ำซ้อนกับ Famo (famotidine) เป็นปัญหา P18
- **Kudona (自費)**: เกมถือว่าเป็น **glucosamine** (อาหารเสริมข้อเข่า จ่ายเงินเอง)

## รายละเอียดที่แต่งเพิ่ม (ขอให้อาจารย์ตรวจ)
- วันเยี่ยม: ศุกร์ 29 เม.ย. 2022 บ่ายสองครึ่ง (อีก 2 วันลุงจะอายุครบ 89 แต่ใช้อายุ 88 ในการคำนวณ)
- ภรรยาชื่อ "อาเหมย" (阿梅) วันนี้หยุดงาน ต้องออกไปเข้าเวรดึกตอน 4 โมงเย็น (เป็นเหตุผลที่เวลาเยี่ยมมีจำกัด) สุนัขชื่อ "เจ้าดำ" (小黑)
- **ความลับ (P8):** วันที่ภรรยาเข้าเวรดึกไม่มีใครโทรเตือนตอนเช้า ลุงจึงลืมยาเช้า (กล่องยาช่องเช้าวันอังคาร/พฤหัสฯ ยังเต็ม) แล้วตอนกลางคืนกินยาเช้ากับเย็นพร้อมกันเพราะ "เสียดายยาของรัฐบาล" (รวม glipizide สองเท่า) คืนวันพฤหัสฯ ที่แล้วเวียนหัว เหงื่อแตก ล้มในห้องน้ำรวม แต่ไม่บอกใคร เพราะกลัวถูกส่งเข้าบ้านพักทหารผ่านศึก
- หลักฐาน: ยาพ่น Berotec เกือบหมด แต่ Spiolto แทบไม่ได้ใช้ ใบเสร็จยาจ่ายเงินเอง (Kudona, Clarinase) อยู่ในกล่องขนมปังกับสมุดบัญชีบำนาญ รีโมตแอร์ห่อถุงพลาสติก บิลค่าไฟวงแดง
- เภสัชกรผู้สอนในเคสนี้คือ "เภสัชกรเฉิน" (陳藥師) ตามเอกสารเคส (วาดตัวละครใหม่)

## ฉากใหม่: ตรวจการใช้ยาพ่น (บทที่ 4)
1. หอบกะทันหันตอนขึ้นบันได ควรใช้ตัวไหน → **Berotec (สีฟ้า) = ยาฉุกเฉิน** / **Spiolto (สีเขียว) = ยาควบคุมใช้ทุกวัน**
2. ดูลุงสาธิตการใช้ Berotec MDI แล้วเลือกขั้นตอนที่ผิด (ไม่เขย่า, ไม่หายใจออกก่อน, กดก่อนหายใจเข้า, สูดเร็วสั้น, ไม่กลั้นหายใจและถุยยาออก)
3. เรียงขั้นตอนการใช้ Spiolto Respimat (TURN – OPEN – PRESS) 7 ขั้น
4. ซองยาเขียน "วันละ 2 ครั้ง ครั้งละ 2 พ่น" แต่ขนาดมาตรฐานของ Spiolto คือ **2 พ่น วันละครั้ง** → ปรึกษาแพทย์ผู้สั่งยา (พร้อมแนะนำ spacer สำหรับ MDI และให้ลุงทวนวิธีใช้กลับ)

## ฉากค้นบ้าน (ห้องเล็ก 5 ผิงของลุง)
5 โซน: ประตูทางเข้า · ผนังกับชั้นวาง · ข้างเตียง · มุมทำอาหารและหน้าต่าง · โต๊ะเล็ก

| หลักฐาน | จุดซ่อน |
|---|---|
| ⭐ ปฏิทินนัดหมอ + ใบเสร็จคลินิก | ผนัง |
| ⭐ ยาพ่น 2 ตัว (Berotec เกือบหมด / Spiolto แทบไม่ใช้) | ข้างเตียง |
| ⭐ อาหารบูด มีมด | ตู้กับข้าวในมุมทำอาหาร |
| ⭐ รีโมตแอร์ห่อถุง + บิลค่าไฟ | ใต้แอร์ข้างหน้าต่าง |
| ⭐ ฟันปลอมในแก้วโลหะ | ข้างเตียง |
| ⭐ กล่องขนมปัง: สมุดบำนาญ + ใบเสร็จยาจ่ายเอง | ชั้นวางบนผนัง |
| ⭐ กล่องยารายสัปดาห์ (ช่องเช้าอังคาร/พฤหัสฯ ยังเต็ม) | โต๊ะเล็ก |
| ซองยา รพ.ทั่วไป 11 ซอง | ถุงผ้าแขวนหลังประตู |
| ซองยา รพ.เทศบาล (ผิวหนัง) | กล่องรองเท้าข้างเตียง |
| ผลแล็บ | แฟ้มบนชั้นวาง |
| ถุงยาเก่าค้างจากหลายคลินิก | ใต้เตียง |
